# Core Flight System : Framework : App : Listener

This repository contains a demo application (listener_app).

This listener application is a non-flight example application implementation for the cFS Bundle. It is intended to be located in the `apps/listener_app` subdirectory of a cFS Mission Tree.  The Core Flight System is bundled at https://github.com/nasa/cFS, which includes build and execution instructions.

listener_app is an example application that listens for a command from a `talker_app` carrying an integer value and relays the value back to the talker.

This application is based on the sample_app included with the cFS Bundle.
