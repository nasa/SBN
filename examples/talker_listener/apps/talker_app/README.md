# Core Flight System : Framework : App : Talker

This repository contains a demo application (talker_app).

This demo application is a non-flight example application implementation for the cFS Bundle. It is intended to be located in the `apps/talker_app` subdirectory of a cFS Mission Tree.  The Core Flight System is bundled at https://github.com/nasa/cFS, which includes build and execution instructions.

talker_app is an example for how to send a command to and receive a command from another application cFS (`listener_app`).

This application is based on the sample_app included with the cFS Bundle.
